# ESA — сайт заказов + Telegram-бот

## Что умеет
- **Сайт**: услуги и цены, работы, форма заказа, отзывы со звёздами (появляются после вашего одобрения), проверка статуса заказа.
- **Бот для клиентов**: меню, услуги и цены, заказ прямо в чате, «Мои заказы», автоответ на любое сообщение, связь с вами.
- **Бот для вас**: карточка каждого нового заказа с кнопками ✅ Принять / ❌ Отклонить / 🛠 В работе / 🎉 Готово; клиент сразу получает уведомление (при «Принять» — реквизиты MBank/Optima). Ответить клиенту — просто «Ответить» (reply) на его сообщение. Команды: `/orders`, `/o ESA-123456`.
- Защита: проверка секрета у Telegram, ловушка для спам-ботов, лимит заказов с одного адреса, экранирование текста, строгие заголовки безопасности.

## Запуск бота (один раз)
1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя, например `ESA заказы`, и username, например `esa_orders_bot`. Скопируйте **токен**.
2. В Netlify → сайт → *Project configuration → Environment variables* добавьте значения из `.env.example`.
3. Напишите своему боту `/myid` — он пришлёт ваш chat id → впишите в `TG_OWNER_CHAT_ID`, сделайте повторный деплой.
4. Включите webhook:
   ```powershell
   Invoke-RestMethod -Method Post -Uri "https://АДРЕС-САЙТА/api/tg-setup" -Headers @{ "x-setup-secret" = "ВАШ_TG_WEBHOOK_SECRET" }
   ```

## Проверка
```powershell
npm test
```
Локальный просмотр (без Telegram, данные в памяти): `node --experimental-test-module-mocks scripts/preview.mjs` → http://localhost:8899

## Где менять
- Услуги и цены — `netlify/lib/core.mjs` (`SERVICES`), сайт и бот берут их оттуда.
- Работы в портфолио — `public/index.html`, раздел `#works`.
